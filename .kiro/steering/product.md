# Product Overview

MuseMorphose は、Transformer VAE を使って長尺の音楽系列を扱う生成研究基盤です。元のフルソング・ピアノ変換ワークフローに加えて、現在はドラム譜向けのトークン化・難易度付与・学習/生成パイプラインを同一リポジトリ内で運用しています。

## Core Capabilities

- **長尺音楽の潜在表現学習**: 小節単位でエンコードし、潜在変数から系列を再生成する VAE 構成。
- **ドラム特化データ化**: MIDI をドラム用トークンへ変換し、学習用 `pkl` データセットを生成。
- **属性/条件付き生成**: 標準属性（rhythm/polyphony）またはドラム難易度属性を条件として制御可能。
- **複数トークン化方式の運用**: standard と `cp_limb_v1` を設定で切り替え、同一学習基盤で実験可能。
- **再現可能な実験実行**: YAML 設定とタスクスクリプトを中心に、前処理→学習→生成の流れを固定化。

## Target Use Cases

- **音楽生成研究**: アーキテクチャ改良、条件制御、潜在空間設計の比較実験。
- **ドラム演奏モデリング**: 演奏技法や難易度を反映したドラムパターン生成。
- **オフライン制作支援**: バッチ処理で MIDI 生成を回し、複数サンプルを比較・選別する制作フロー。

## Value Proposition

- **研究コードと実運用スクリプトの橋渡し**: `src`（コア実装）と `scripts`/`tasks`（運用）を分離し、試行錯誤しやすい。
- **表現方式の拡張に強い**: トークン方式や条件属性を差し替えても、学習ループの骨格を再利用できる。
- **日本語ドキュメント併用**: ドラム拡張の背景や手順が日本語で整備され、運用ハードルを下げている。
